# DC BEER · Gastos

App web para registrar los gastos de DC BEER con foto de la factura, pantallazo o a mano.

- Hosting: GitHub Pages (gratis)
- Datos: Firebase Realtime Database + Authentication (plan Spark, gratis)
- Lectura de facturas: OCR en el navegador (Tesseract.js, gratis)
- Se instala en la pantalla de inicio del celular y funciona también en el computador
